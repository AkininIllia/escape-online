# ESCAPE ONLINE

Вебзастосунок платформи інтерактивних квестів у реальному часі, розроблений на React, TypeScript та Vite і підготовлений до розповсюдження через Docker Hub.

## Призначення застосунку

**ESCAPE ONLINE** дозволяє користувачам переглядати доступні квест-кімнати, шукати та фільтрувати їх за складністю й статусом проходження, проходити загадки з підказками та створювати власні квести. Стан квестів і прогрес проходження зберігаються у `localStorage`.

## Використані технології

- **React** + **TypeScript**
- **Vite** (збірка та dev-сервер)
- **React Router (`react-router-dom`)** — маршрутизація між сторінками каталогу, детальної кімнати квесту та створення нового квесту
- **Docker** та **Nginx (`nginx:alpine`)** — контейнеризація та віддача зібраної статики

## Структура Dockerfile та принцип Multi-stage build

У проєкті реалізовано:
- `Dockerfile.basic` — базовий одноетапний варіант на базі `node:22-alpine` для порівняння;
- `Dockerfile` — оптимізований багатоетапний (`multi-stage`) файл із `.dockerignore`, `npm ci` та кешем збірки BuildKit (`--mount=type=cache,target=/root/.npm`).

**Як працює multi-stage build:**
1. **Етап 1 (`builder` на `node:22-alpine`)** — копіює залежності, встановлює пакети через `npm ci` з кешуванням BuildKit, переносить вихідний код і збирає production-версію у директорію `/app/dist`.
2. **Етап 2 (фінальний образ на `nginx:alpine`)** — переносить лише готову папку `/app/dist` у `/usr/share/nginx/html` та запускає легкий вебсервер `nginx`. Інструменти збірки та вихідний код не потрапляють у фінальний образ.

## Команди завантаження та запуску

Завантажити образ (наприклад, версію `2.0`):

```bash
docker pull illiaa07/escape-online:2.0
```

Запустити контейнер на порту `8080`:

```bash
docker run -d -p 8080:80 --name escape-online illiaa07/escape-online:2.0
```

Після запуску застосунок доступний за адресою http://localhost:8080.
